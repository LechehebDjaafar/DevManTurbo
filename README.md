# DevManTurbo ⚡

### أنشئ فيديوهات قصيرة بمساعدة الذكاء الاصطناعي

نسخة DevManTurbo المخصّصة أنشأها وطوّرها **Djaafar Lecheheb** من ورقلة، الجزائر. تستند هذه النسخة إلى مشروع [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo)، مع الاحتفاظ بنسبة الفضل إلى المشروع الأصلي ومؤلفه.

أدخل موضوع الفيديو أو نصّه، ثم استخدم التطبيق لإعداد النص والكلمات المفتاحية، واختيار المواد المرئية والصوتية، وإضافة الترجمة والموسيقى، وإنتاج فيديو قصير.

**الواجهة متاحة بالعربية:** اختر «العربية» من قائمة اللغات. تُعرض الواجهة من اليمين إلى اليسار، مع إبقاء الحقول التقنية والروابط والرموز البرمجية باتجاهها المناسب.

## التشغيل على Windows

في الحزمة المحمولة، شغّل `start.bat` لفتح واجهة الويب، أو `api.bat` لبدء واجهة API. قد تحتاج إلى إعداد مفاتيح API الخاصة بمزوّدي النصوص والصوت والمواد المرئية قبل استخدام الخدمات المتصلة بالإنترنت.

للتثبيت من Python، يتطلب المشروع Python 3.11 أو أحدث:

```sh
python -m pip install mpt
mpt webui
```

## اللغة العربية

اختر العربية كلغة للواجهة. ويمكن اختيار العربية أيضاً كلغة لنص الفيديو؛ يعتمد توليد الصوت على الأصوات واللغات التي يدعمها مزوّد تحويل النص إلى كلام المحدد.
